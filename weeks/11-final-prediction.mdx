교재 13장은 방법 세 가지를 Approach 1, 2, 3으로 제시하고, 이 노트도 이 순서로 간다.

| 교재 | 방법 | 내놓는 것 |

세 방법을 본 뒤에는 고른 예측을 테스트에서 평가하고 다른 사람에게 전달하는 일을 다룬다.
교재 내용은 여기까지이고, 노트의 마지막 절은 15주차 M3(Milestone 3) 최종 발표와 보고서의 평가 기준을 안내한다.

**읽기 자료**: 교재 13장 [Producing the Final Prediction Results](https://vdsbook.com/13-final_ml).[^vds13]

## 1. 가장 좋은 모델 하나

지금까지는 훈련 데이터를 하나로 정해 두고 알고리즘만 바꿔 가며 비교했다.
그런데 결측을 어떻게 채울지처럼 정제·전처리에서 내리는 판단도 예측을 바꾼다.
판단이 다르면 훈련 데이터가 달라지기 때문이다.
그래서 이 노트에서 모델 하나는 **훈련 데이터 한 벌로 알고리즘 하나를 학습한 결과**를 가리킨다.
알고리즘이 같아도 훈련 데이터가 다르면 다른 모델이다.
교재는 이것을 predictive fit, 줄여서 fit이라 부른다.[^vds13]
**알고리즘마다 전처리를 달리한 여러 훈련 데이터로 학습해 보고, 그렇게 얻은 모델들 가운데에서 최종 예측을 고른다.**

펭귄 자료로 보자.[^penguins]
알고리즘은 9주차의 선형회귀와 [10b](/lecture/2026f-applied-data-science/10b-trees-and-xgboost#41-회귀에서의-부스팅)의 XGBoost 둘이다.
전처리 판단은 성별 결측을 어떻게 다루느냐이고, 선택지는 셋이다.
9주차에는 성별을 특성으로 쓰지 않았는데, 성별은 몸무게와 관련이 크고 훈련 239마리 가운데 7마리는 성별이 기록되지 않았다.
선택지 셋과 알고리즘 둘을 곱하면 모델은 3 × 2 = 6개다.
아래 표는 여섯 모델의 교차검증 MAE(g)이고, 낮을수록 좋다.
결측 행을 제거한 모델은 성별이 없는 펭귄을 예측할 수 없으므로, 여섯 모델이 모두 예측할 수 있는 232마리에서만 쟀다.

| 성별 결측 처리 | 선형회귀 | XGBoost |
|---|---|---|
| 성별을 쓰지 않음 | 254 | 271 |
| 결측 행 제거 | 234 | 240 |
| 최빈값으로 대체 | 237 | 245 |

오차가 낮은 네 모델에는 결측 행 제거와 최빈값으로 대체가 둘씩 섞여 있다.
**이렇게 한 판단의 여러 선택지가 성능 좋은 모델에 고루 섞여 있으면, 예측 성능은 그 판단에 민감하지 않다(안정적이다)고 본다.**
반대로 성별을 쓰지 않은 두 모델은 오차가 가장 크므로, 성별을 쓰느냐 마느냐에는 민감하다.

모델은 오차만 보고 고르지 않는다.
오차가 가장 낮은 모델은 결측 행을 제거한 선형회귀(234 g)이지만, 이 모델은 성별이 없는 펭귄에 예측을 내지 못한다.
최빈값으로 대체한 선형회귀는 3 g 높을 뿐이고 모든 펭귄을 예측한다.
XGBoost와 견주면 하이퍼파라미터를 고를 필요가 없고 계수로 설명할 수 있다.
그래서 이 노트는 최빈값으로 대체한 선형회귀 모델을 고른다.
이 모델의 교차검증 MAE를 훈련 239마리 전체로 다시 재면 239 g이다.
교재도 예측 성능 대신 도메인 지식, 해석 가능성, 계산 부담을 기준으로 모델을 골라도 된다고 하며, 어떤 모델도 문제가 요구하는 성능에 못 미치면 아무것도 쓰지 말라고 권한다.[^vds13]

## 2. 앙상블

10주차의 랜덤 포레스트는 같은 종류의 트리 여러 개의 예측을 합친 앙상블이었다.
앙상블의 구성원이 꼭 같은 종류일 필요는 없고, 선형회귀와 XGBoost처럼 서로 다른 알고리즘으로 학습한 모델을 합쳐도 된다.
연속값은 예측을 평균하고, 분류는 다수결을 쓴다.[^vds13]
앙상블도 관측마다 예측값 하나를 내므로, 모델 하나와 같은 지표로 평가하고 비교할 수 있다.

성능이 크게 나쁜 모델까지 합치면 평균이 나빠질 수 있다.
그래서 합치기 전에 검증 성능이 나쁜 모델을 걸러 낸다.
교재는 이 선별을 predictability screening이라 부른다.[^vds13]
선별은 앙상블뿐 아니라 뒤에 나올 구간을 만들 때도 먼저 한다.
거르는 기준은 문제에 맞게, 테스트를 보기 전에 정한다.
교재가 드는 예는 성능 상위 10%의 모델만 남기는 것이다.
이 노트는 모델이 여섯뿐이라, 모든 펭귄을 예측할 수 있는 모델 가운데 알고리즘마다 오차가 가장 낮은 것을 하나씩 남겼다.
그러면 최빈값으로 대체한 두 모델이 남는다(훈련 239마리 전체의 교차검증 MAE는 선형회귀 239 g, XGBoost 246 g).

**평균은 여러 모델의 오차가 서로 상쇄될 때 도움이 된다.**
한 모델이 실제보다 무겁게, 다른 모델이 가볍게 예측하면 평균은 실제에 가까워진다.
두 모델이 같은 방향으로 틀리면 평균해도 오차가 남는다.
교차검증 예측에서 두 모델이 같은 방향으로 틀린 펭귄은 239마리 가운데 211마리(88%)였다.
두 모델이 같은 특성만 보는 탓이 크다.
그래서 두 예측을 평균한 앙상블의 교차검증 MAE는 238 g으로, 선형회귀 하나(239 g)와 거의 같다.
**앙상블이 가장 좋은 모델 하나보다 항상 나은 것은 아니다.**
숫자 하나로 내는 예측(점 예측)은 앞에서 고른 선형회귀를 그대로 쓴다.

## 3. PPI

앙상블의 평균은 숫자 하나라서, 모델마다 예측이 비슷했는지 크게 달랐는지는 알 수 없다.
교재의 **PPI**는 그 차이를 구간으로 보여 준다.[^vds13]
이름에 든 perturbation은 2주차에서 본 대로, 데이터나 알고리즘을 조금 바꿔 보는 것이다.
구간은 예측값 하나가 아니라서 MAE로 잴 수 없고, 포함률과 폭으로 평가한다.
교재는 PPI를 몸무게 같은 연속값 예측에만 쓴다.
분류에서는 예측 확률로 구간을 만들 수는 있어도 그 포함률을 셀 수 없어 보정하기 어렵다고 본다.[^vds13]

구간은 다음 순서로 만든다(교재 [그림 13.5](https://vdsbook.com/13-final_ml#fig-interval-diagram)).

1. 선별을 통과한 모델을 쓴다.
   여기서는 앞에서 남긴 두 모델이다.
2. 훈련 데이터의 부트스트랩 표본을 100개 만들고, 표본마다 두 모델을 다시 학습한다.
   이렇게 얻은 모델은 2 × 100 = 200개다.
3. 새 펭귄 한 마리를 200개 모델에 넣어 예측 200개를 얻는다.
4. 200개의 5백분위수와 95백분위수를 구간의 양 끝으로 삼는다.

**이 구간은 예측 200개의 90%를 담는다. 실제 몸무게의 90%를 담는다는 뜻이 아니다.**
3주차에서 본 **포함률**(coverage)은 구간들 가운데 실제 값을 담은 구간의 비율이다.
훈련 239마리에 교차검증으로 구간을 만들어 세면 포함률은 41%다.
구간의 폭은 우리가 바꿔 본 것(훈련 표본, 알고리즘) 때문에 예측이 달라진 만큼만 넓기 때문이다.
치수·종·성별이 같은 펭귄들의 실제 몸무게가 서로 다른 것은 예측 200개 어디에도 들어 있지 않다.

목표가 90%라면 구간을 넓혀야 하고, 이렇게 포함률을 목표에 맞추는 일을 **보정**(calibration)이라 한다.
교재의 방법은 중앙값을 그대로 두고 양쪽 끝을 같은 배수 $\gamma$(감마)만큼 멀리 미는 것이다.[^vds13]
아래 식에서 $q_{0.05}$는 5백분위수, $q_{0.95}$는 95백분위수다.

$$
\Big[\,\text{중앙값}-\gamma\,(\text{중앙값}-q_{0.05}),\;\; \text{중앙값}+\gamma\,(q_{0.95}-\text{중앙값})\,\Big]
$$

$\gamma=1$이면 넓히기 전의 구간이다.
$\gamma$는 모든 펭귄에 같은 값을 쓰고, 여러 값을 해 보아 포함률이 목표에 가장 가까운 값을 고른다.
펭귄 자료에서는 $\gamma=3.76$일 때 교차검증 포함률이 90%가 되고, 구간의 평균 폭은 321 g에서 1,208 g으로 늘어난다.

<Details summary="재현 조건과 코드">

- 모델: 성별을 최빈값으로 대체한 두 모델.
  XGBoost의 하이퍼파라미터 조합은 깊이(2, 3, 4), 트리 수(50, 100, 200, 400), 학습률(0.03, 0.1)을 곱한 24개이고, `GridSearchCV`(`KFold(5, shuffle=True, random_state=0)`, MAE 기준)로 고른다.
  성별 최빈값은 검증 폴드의 정보가 학습에 새지 않도록 폴드마다 그 학습 부분에서 다시 구하며, 이를 위해 특성 만들기와 XGBoost를 파이프라인으로 묶는다.
- 중첩 교차검증: 가장 잘 나온 조합의 검증 점수를 그대로 성능으로 보고하면, 운 좋게 잘 나온 점수를 고른 셈이라 실제보다 좋아 보인다.
  그래서 평가용 폴드는 따로 남겨 두고, 나머지 훈련 부분 안에서 다시 교차검증을 해 조합을 고른다.
  본문의 XGBoost 교차검증 MAE와 구간은 이렇게 구했고, 테스트 구간용으로는 239마리 전체에서 고른 학습률 0.03, 깊이 3, 트리 200개를 쓴다.
- XGBoost는 결측을 그대로 받을 수도 있지만, 두 알고리즘에 같은 훈련 데이터를 주려고 여기서는 쓰지 않았다.
- 부트스트랩: 표본 100개를 두 모델이 함께 쓰고, 표본마다 성별 최빈값을 다시 구한다.
  교차검증에서는 폴드마다 그 훈련 부분에서, 테스트 구간용으로는 훈련 239마리에서 뽑는다.
  난수는 `numpy.random.default_rng(0)` 하나를 이 순서로 이어 쓰고, 표본 하나는 `rng.integers(0, n, n)`(n은 그 훈련 부분의 펭귄 수)으로 뽑는다.
- 교차검증: `KFold(5, shuffle=True, random_state=0)`.
- 구간: 예측 200개의 5·95백분위수.
  $\gamma$는 0.5부터 0.01 간격으로 7.99까지 훑어 포함률이 90%에 가장 가까운 값을 골랐고, 같은 포함률이 나오는 값이 여럿이면(3.76–3.87) 가장 작은 값을 택했다.
- 환경: xgboost 3.4.1, scikit-learn 1.9.1, numpy 2.5.4, pandas 3.1.1.

아래 코드는 교차검증 구간을 만들고 $\gamma$를 고르는 데까지 재현한다.

```python
import numpy as np
import pandas as pd
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import GridSearchCV, KFold, train_test_split
from sklearn.pipeline import make_pipeline
from xgboost import XGBRegressor

url = ("https://raw.githubusercontent.com/allisonhorst/palmerpenguins/"
       "main/inst/extdata/penguins.csv")
cols = ["flipper_length_mm", "bill_length_mm", "bill_depth_mm", "species"]
d = pd.read_csv(url).dropna(subset=cols + ["body_mass_g"])
train, test = train_test_split(d, test_size=0.3, random_state=0)
y = train["body_mass_g"].to_numpy()

def features(df, mode):  # 성별 결측은 mode로 채운다
    X = df[cols[:3]].copy()
    X["Chinstrap"] = (df["species"] == "Chinstrap").astype(float)
    X["Gentoo"] = (df["species"] == "Gentoo").astype(float)
    X["male"] = (df["sex"].fillna(mode) == "male").astype(float)
    return X

class Features(BaseEstimator, TransformerMixin):  # 최빈값을 학습 부분에서만 구한다
    def fit(self, df, y=None):
        self.mode_ = df["sex"].mode()[0]
        return self

    def transform(self, df):
        return features(df, self.mode_)

grid = {"xgbregressor__max_depth": [2, 3, 4], "xgbregressor__n_estimators": [50, 100, 200, 400],
        "xgbregressor__learning_rate": [0.03, 0.1]}
cv = KFold(5, shuffle=True, random_state=0)
rng = np.random.default_rng(0)
P = np.empty((len(train), 200))  # 펭귄마다 한 행, 모델마다 한 열
for tr, va in cv.split(train):
    T, V = train.iloc[tr], train.iloc[va]
    pipe = make_pipeline(Features(), XGBRegressor(random_state=0))
    search = GridSearchCV(pipe, grid, cv=cv, scoring="neg_mean_absolute_error").fit(T, T["body_mass_g"])
    params = {k.split("__")[1]: v for k, v in search.best_params_.items()}
    for b in range(100):
        B = T.iloc[rng.integers(0, len(T), len(T))]
        mode = B["sex"].mode()[0]  # 표본마다 최빈값을 다시 구한다
        for k, model in enumerate([LinearRegression(), XGBRegressor(random_state=0, **params)]):
            model.fit(features(B, mode), B["body_mass_g"])
            P[va, 100 * k + b] = model.predict(features(V, mode))  # 앞 100열은 선형회귀, 뒤 100열은 XGBoost

q05, med, q95 = np.percentile(P, [5, 50, 95], axis=1)
def calibrate(g):  # 포함률과 평균 폭
    lo, hi = med - g * (med - q05), med + g * (q95 - med)
    return ((lo <= y) & (y <= hi)).mean(), (hi - lo).mean()

gammas = np.round(np.arange(0.5, 8, 0.01), 2)
best = min(gammas, key=lambda g: abs(calibrate(g)[0] - 0.9))
print(calibrate(1), best, calibrate(best))  # 약 (0.41, 321), 3.76, (0.90, 1208)
```

## 4. 테스트와 전달

모델 하나, 앙상블, PPI 가운데 무엇을 내놓을지는 문제에 달려 있다.
교재는 연속값 예측에서는 불확실성까지 전하는 PPI를 권한다.
숫자 하나만 내야 하면 모델 하나와 앙상블 가운데 검증 성능이 좋은 쪽을 고르고, 계산 부담과 해석 가능성이 더 중요하면 모델 하나를 고른다.[^vds13]
펭귄 예에서는 선형회귀의 예측값 하나와 보정된 구간을 함께 내놓는다.

고른 설정(전처리 판단, 알고리즘, 하이퍼파라미터, $\gamma$)을 고정해 훈련 데이터 전체로 다시 학습하고, 테스트에서 한 번 평가한다.
**테스트 결과를 본 뒤에는 모델을 더 고치지 않는다.**
테스트 점수를 올리려고 고치기 시작하면 테스트는 더 이상 새 데이터에서의 성능을 알려 주지 못하고, 다시 평가하려면 새 데이터가 또 필요하다.

테스트 103마리에서 선형회귀 모델의 MAE는 234 g이다.
모든 펭귄을 훈련 평균으로 예측하는 기준 모델의 MAE는 647 g이다.
보정된 구간은 103개 가운데 92개가 실제 몸무게를 담아 포함률이 89%이고, 평균 폭은 1,180 g이다.
포함률만 높이려면 구간을 넓히면 되므로, 포함률은 평균 폭과 함께 보고한다.

<Figure src={ppiTest.src} alt="테스트 펭귄 103마리의 보정된 PPI. 가로축은 실제 몸무게, 세로축은 구간이다. 회색 세로 막대 92개는 모두 점선 대각선을 가로지르고, 대각선에 닿지 않는 주황색 막대 11개는 실제 몸무게를 담지 못한 구간이다" caption="테스트 펭귄 103마리의 보정된 구간(γ = 3.76). 점은 모델 200개 예측의 중앙값이고, 주황색 11개는 실제 몸무게를 담지 못한 구간이다." wide />

결과를 다른 사람이 쓰려면 입력 단위와 전처리 규칙(예: 성별이 없으면 훈련 데이터의 최빈값으로 채움)을 함께 전해야 한다.
새 데이터도 훈련 데이터와 같은 방식으로 전처리해야 그 모델로 예측할 수 있기 때문이다.
코드를 공개해도 코드를 다루지 못하는 사용자는 예측을 쓸 수 없다.
그런 사용자에게는 값을 입력하면 예측이 나오는 입력 양식이나 데모를 준다.[^vds13]

## 5. M3 최종 발표와 보고서

15주차 M3에서는 팀이 한 학기 동안 한 연구를 발표와 보고서로 전달한다.
M3는 최종 산출물 점수 40점을 정하는 평가이고, 발표 20점과 보고서 20점으로 나눠 아래 기준표대로 엄격하게 채점한다.
기준은 논문을 심사할 때 보는 것과 같은 네 가지이고, 기준 하나가 5점이다.
발표와 보고서의 기준은 같으며, 전달에서 확인하는 것만 다르다.

### 5.1 발표

발표 시간은 팀당 15분이다.
15분 안에 연구의 처음부터 끝까지를 담아야 하므로, 발표 전체가 하나의 이야기로 완결되어야 한다.
한 일을 모두 발표하지 않는다.
청중이 꼭 알아야 하는 것을 먼저 정하고, 그것을 전달하는 데 필요한 내용만 남긴다.
청중은 이 연구를 처음 듣는다고 생각하고 준비한다.
M1과 M2에서 이미 말한 내용이라도, 정의가 필요한 용어·변수·지표는 다시 정확하게 정의한다.
M3 발표에는 피드백을 하지 않고, 기준표에 따라 채점만 한다.

| 기준 (각 5점) | 확인하는 것 |
|---|---|
| 문제 정의 | <ul><li>풀려는 질문이 무엇인지 분명한가.</li><li>그 질문이 왜 중요한지, 관련 연구와 무엇이 다른지 설명하는가.</li></ul> |
| 방법의 타당성 | <ul><li>데이터와 분석 방법이 질문에 답하기에 알맞은가.</li><li>정제·전처리·모델 선택에서 내린 판단의 근거를 밝히는가.</li><li>평가 지표와 비교 기준이 적절한가.</li></ul> |
| 결과와 결론 | <ul><li>결론마다 그것을 뒷받침하는 결과를 보이는가.</li><li>결과가 보여 주는 것보다 강하게 주장하지 않는가.</li><li>결론이 판단이나 데이터를 바꿔도 유지되는지 확인했고, 한계를 밝히는가.</li></ul> |
| 전달 | <ul><li>질문에서 결론까지 15분 안에 하나의 이야기로 완결되는가.</li><li>한 일을 나열하지 않고, 전달할 핵심에 필요한 내용만 골랐는가.</li><li>처음 듣는 사람이 따라올 수 있게 용어·변수·지표를 정확하게 정의하는가.</li></ul> |
