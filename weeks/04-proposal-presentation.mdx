제안 발표에서는 팀의 질문을 이번 학기에 실행할 수 있는 연구 계획으로 설명한다.
아직 얻지 못한 자료나 실행하지 않은 분석은 계획으로 표시하고, 확인한 사실과 구분한다.
**팀당 발표 시간은 10분이다. 발표 전까지 사용할 데이터를 적어도 한 번 직접 열어 보고
표본과 구조를 확인해야 한다.** 제출 기한·파일 형식과 Quiz 1의 문항·배점은 별도 공지를 따른다.

## 1. 발표 필수 내용

다음 여섯 가지를 모두 포함해 발표한다. 문헌 조사와 데이터 확인을 근거로,
이번 학기에 무엇을 어떤 순서로 진행할지 설명한다.

| 필수 내용 | 발표에서 보여 줄 내용 |
|---|---|
| 주제 | 연구 질문, 대상과 범위, 결과가 도움이 될 사람이나 상황 |
| 주제 선정 이유·문헌 조사 | 주제의 필요성, 관련 연구의 질문·데이터·접근, 우리 프로젝트와의 연결, 문헌 출처 |
| 사용할 데이터 | 출처·사용 조건·확보 상태, 직접 열어 본 표본, 자료의 규모와 주요 변수 |
| 앞으로 진행해 볼 내용 | 전처리·탐색·분석의 계획, 먼저 시도할 방법과 결과를 확인할 기준 |
| 예상되는 어려움 | 실제 데이터에서 발견한 문제, 예상되는 제약, 해결 방향과 필요한 도움 |
| 간트 차트 | 작업별 시작·종료 시점, 담당자, 마일스톤과 진행 상황 |

문헌 조사는 필수다. 참고문헌 목록을 나열하는 데서 그치지 않고, 관련 연구가 무엇을
다루었으며 그것이 우리 주제 선정과 접근에 어떤 근거가 되었는지 설명한다.

분석 계획은 현재까지 확인한 자료에 맞춰 제시한다. 예측 프로젝트라면 입력과 target,
비교할 baseline과 평가 방법을 생각해 본다. 구조 탐색 프로젝트라면 어떤 구조를 찾고
어떤 근거로 그 결과의 유용성을 판단할지 설명한다. 아직 실행하지 않은 부분은 계획으로 밝힌다.

## 2. 데이터 확인과 예상되는 어려움

“자료를 받을 예정”이나 데이터 소개 페이지의 화면만으로는 실제 데이터를 확인한 것이 아니다.
파일을 직접 읽고 한 행 또는 한 표본이 무엇을 나타내는지, 어떤 변수가 있으며 크기와 형식은
어떤지 확인한다. 이미지나 텍스트 자료라면 실제 샘플과 레이블·메타데이터 구조를 살핀다.
전체 자료가 매우 크다면 먼저 일부 표본을 열고, 확인한 범위를 밝힌다.
공개할 수 없는 표본은 발표 자료에 그대로 싣지 않고, 변수 구조나 집계 결과로 설명한다.

어려움은 직접 확인한 문제와 앞으로 예상하는 문제를 구분해 제시한다.

| 데이터에서 확인한 상황 | 프로젝트에 미치는 영향 | 검토할 대응과 필요한 도움 |
|---|---|---|
| 일부 주문에 수령 시각이 없음 | 해당 주문의 대기 시간을 계산하기 어려움 | 누락 원인 확인, 사용 범위 조정, 결측 처리 방법 |
| 두 파일의 식별자가 일치하지 않음 | 필요한 변수를 한 표에 결합하기 어려움 | 결합 기준과 중복 확인 방법 |
| 관심 범주의 표본이 적음 | 학습과 평가가 불안정할 수 있음 | 추가 수집 가능성, 평가 방법과 범위 조정 |

위 표는 식당 프로젝트를 바탕으로 한 예시다. 우리 팀의 데이터에서 무엇을 발견했는지,
어떤 도움을 받으면 다음 단계로 나아갈 수 있는지 구체적으로 설명한다.
**발표에서 나온 어려움은 가능한 범위에서 이후 수업의 보완 설명과 강의 내용에 반영할 예정이다.**

## 3. 간트 차트로 프로젝트 진행 관리하기

간트 차트(Gantt chart)는 작업별 시작과 종료 시점을 시간축에 표시하는 일정표다.
문헌 조사, 데이터 확인·전처리, 탐색, 모델링·평가, 발표·보고서 준비를 주차별로 배치한다.
각 작업에는 담당자를 적고, 8주차 중간 발표와 16주차 최종 발표·보고서까지의 일정을 보여 준다.

작업 순서도 드러나야 한다. 예를 들어 데이터 결합 가능성을 먼저 확인해야 모델링을 시작할
수 있다면 두 작업의 관계를 일정에 반영한다. 어려움이 생길 수 있는 작업에는 확인 시점과
대안을 정하고, 진행 중에는 계획 대비 완료·진행·지연 상태를 표시해 차트를 갱신한다.
발표용 일정표를 프로젝트의 진행 관리에도 계속 사용한다.

## 4. 피드백을 다음 결정으로 바꾸기

청중은 “좋은 주제다” 대신 질문·자료·평가 가운데 연결이 끊긴 지점을 구체적으로 묻는다.
발표 후 팀은 아래 기록을 남긴다.

| 받은 질문 | 확인할 증거 | 담당자 | 확인 시점 | 계획 변경 또는 유지 이유 |
|---|---|---|---|---|
| 수령 기록 누락은 얼마나 되는가 | 시간대별 누락률과 제공기관 설명 | 팀에서 지정 | 팀에서 지정 | 확인 후 기록 |

발표 내용, 문헌 근거, 실제 데이터 확인, 간트 차트와 피드백 기록이 같은 연구 질문과
실행 계획을 가리키는지 마지막으로 점검한다. 이 표는 준비용 기준이며 별도의 채점 배점표가 아니다.
